# Startup Backlinks

[中文](./README.md) | **English**

A curated and manually verified list of places where **startups, SaaS products, AI tools, and indie makers** can launch products, reach early adopters, and build relevant backlinks.

This repository focuses on actionable opportunities with public submission paths—not dead directories, link farms, or vague lists. It currently contains **65 published resources** from [BlinkLib](https://blinklib.com/backlink-resources). Browse the live directory for updated data, filters, and submission workflows.

> Submission rules, pricing, traffic, and link attributes can change. Verify each platform before submitting.

## Why This List?

Many backlink lists are outdated or fail to explain whether you can actually submit a product. The resources here are selected for their relevance to startups and software, active submission process, potential for referral traffic or brand exposure, and ability to provide a public product or profile page.

Each entry includes:

| Field | Description |
| --- | --- |
| Platform | Website or platform name, linked directly to its submission page when available |
| Access | Whether submission is free, paid, or offers both options |
| DR | Domain Rating when available |
| Monthly traffic | Estimated monthly website traffic |
| Link | Reported link attribute: dofollow, nofollow, UGC, no direct link, or unknown |

## Contributing

Found a broken link or a useful startup resource that is missing? Open an issue or submit a pull request.

Please include as much of the following information as possible:

```text
Name:
Website:
Submit URL:
Category:
Pricing:
Link Type:
Review Required:
Notes:
```

Please do not submit spam websites, PBNs, link farms, dead directories, irrelevant general-purpose websites, or sites without a public submission method. The goal is to keep this list useful, clean, and verified.

For a maintained, searchable version of this dataset, visit [BlinkLib Backlink Resources](https://blinklib.com/backlink-resources).

## Disclaimer

This repository does not guarantee rankings, traffic, indexing, or SEO improvements. Backlink attributes and submission policies may change over time, so always verify the latest information before submitting your website.

We do not recommend buying links purely to manipulate search rankings or using spammy link-building practices.
